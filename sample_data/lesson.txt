Machine learning is a method for building systems that learn patterns from examples rather than following only hand-written rules. A dataset is commonly divided into training, validation, and test sets. The training set is used to adjust a model's parameters. The validation set helps developers compare model choices and tune hyperparameters. The test set should remain unseen until the final evaluation so it can estimate generalization fairly. Overfitting happens when a model memorizes quirks of the training data and performs poorly on new examples. Regularization can reduce overfitting by discouraging unnecessary complexity. Precision measures how many predicted positive cases were actually positive. Recall measures how many of the actual positive cases the model found. Accuracy can be misleading when one class is much more common than another. Cross-validation repeats training across several data splits to produce a more stable performance estimate. A responsible evaluation also checks bias, robustness, latency, and the cost of mistakes in the real setting.
